# План реализации

Спецификация: ../../research/mvp-design.md. Выполнение в текущей сессии по указанию пользователя.

1. Сервер Node.js / SQLite: приглашения, cookie-сессии, закрытый API тем и ответов. Файлы server/db.mjs, app.mjs, index.mjs, invite.mjs. Проверить отказ без сессии, отзыв приглашений, источник запросов, ограничения текста, повторную отправку и сохранение базы.
2. Курс: src/course.ts, шесть тем с испанскими объяснениями, 36+ карточек, слайды reveal.js и упражнения с подсказками.
3. Интерфейс: src/main.ts, style.css, progress.ts. Повторение ts-fsrs, прогресс, экспорт/импорт с проверкой, Доска с сохранением черновика при ошибке и опросом сервера.
4. Проверка: node:test для API, production-сборка и браузерное прохождение урока и переписки в двух сессиях.
5. README: запуск, приглашения, размещение, резервные копии, ограничения голосового этапа. Подготовить архив исходников.

Особое внимание: повреждённое локальное хранилище, разные устройства, повтор запросов, недоступный сервер и вредоносная разметка сообщений.
