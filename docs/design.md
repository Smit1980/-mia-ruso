# Русский для Мии — проект первого MVP

## Назначение

Учебное приложение для Мии, 12 лет, испаноговорящей начинающей ученицы русского языка. Второй участник — её родственник в России, который отвечает на сообщения. Других учеников и публичной регистрации нет.

## Учебный раздел

Интерфейс и объяснения на испанском. Шесть тем: первые буквы, приветствия, знакомство, семья, числа 1–10, любимые вещи. Каждая тема содержит 4–6 слайдов reveal.js, 6–8 карточек и короткие упражнения. Повторение карточек планирует ts-fsrs. Ошибки сопровождаются понятной подсказкой. Прогресс сохраняется в браузере, предусмотрены экспорт и импорт JSON. Работа на телефоне и компьютере, управление клавиатурой.

## Вход

Без почты и вводимого пароля: две закрытые ссылки-приглашения с отдельными ролями «ученица» и «родственник». Это два участника переписки, а не два ученика.

Сервер создаёт криптографически случайные ключи приглашений; хранит их хеши. При открытии приглашения ключ обменивается на сессию в HttpOnly cookie, после чего браузер переходит на URL без ключа. Ключи и сессии не попадают в GitHub и логи приложения. В production HTTPS, Secure cookie, SameSite и проверка источника изменяющих запросов. Возможность отозвать приглашение и связанные сессии через административную команду. Регистрации и восстановления по почте нет. Потеря ссылки решается выпуском новой ссылки администратором. Владелец ссылки получает доступ соответствующего участника.

## Доска

Закрытая доска только для двух участников. Создание темы с заголовком и текстом, ответы внутри темы, автор и дата каждого сообщения. Темы сортируются по последнему сообщению. Новые ответы появляются при обновлении и периодическом опросе сервера; realtime-соединения в первом выпуске не нужны.

Мия начинает писать на испанском, затем на английском согласно текущему сообщению пользователя. Это не меняет целевой язык учебных уроков — русский. Автоматический перевод и исправление AI в MVP не включены.

Сообщения — обычный текст, без HTML, вложений и аудио. Пустые сообщения не принимаются. Заголовок до 120 символов, сообщение до 4000 символов. Обе роли могут создавать темы и отвечать. При сбое отправки текст остаётся в форме, показывается ошибка; повторная отправка с тем же идентификатором не создаёт дубликат. Доступ к API и каждой теме требует сессии.

## Технологии и хранение

Frontend: Vite + TypeScript, reveal.js, ts-fsrs. Backend: Node.js с небольшим HTTP API, SQLite для приглашений, сессий, тем и сообщений. Одна установка приложения обслуживает обоих участников. Учебный контент хранится отдельно в файлах проекта. Учебный прогресс в первом выпуске локальный; сообщения общие, в серверной базе.

SQLite хранится вне Git, предусмотрены инструкция резервного копирования и восстановление. API ограничивает частоту входов и отправки сообщений. Отображение текста исключает исполнение разметки пользователя. При недоступности сервера учебные экраны могут оставаться открытыми, но переписка требует соединения.

## Запуск и размещение

Исходники и инструкции — GitHub. Локальный запуск frontend и backend по README. Production-сборку и API обслуживает один сервер, чтобы не усложнять cookies и CORS. GitHub Pages сам по себе не обеспечивает хранение переписки и не является местом запуска backend.

Для общения между Коста-Рикой и Россией нужен доступный интернет-сервер или защищённый доступ к постоянно включённому компьютеру пользователя. Выбор хостинга не блокирует создание и локальную проверку MVP. Публикация требует конкретного GitHub-репозитория и места размещения; они ещё не указаны. Рабочая /workspace не является компьютером пользователя: перенос и локальный запуск описываются в README.

## Проверка

Проверить прохождение урока, сохранение прогресса, расписание повторений, экспорт/импорт и мобильный интерфейс. Для Доски — обмен сообщениями в двух отдельных браузерных сессиях, сохранение после перезапуска, отказ без сессии, отзыв доступа, обработку пустых/длинных сообщений, отображение опасной разметки как текста и отсутствие дубликатов при повторе запроса. Проверить чистую установку и production-сборку.

## Следующий этап

Голосовая диктовка, озвучка и генерация аудиофайлов после рабочего текстового выпуска. Поддержку русского голоса и локального распознавания проверить на фактическом устройстве Мии. Новые сообщения пока не отправляют уведомлений по почте или мессенджерам.
