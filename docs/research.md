# Русский для Мии: исследование и предложение MVP

Дата: 1 октября 2026 года. Статус: исследование завершено, архитектура предложена; приложение ещё не реализовано.

## Цель

Мия, 12 лет, живёт в Коста-Рике и не говорит по-русски. Интерфейс и объяснения — на испанском, изучаемый язык — русский. Предположение: занятия по 5–10 минут, использование телефона и компьютера. Первый выпуск: текст, карточки, слайды. Голос — следующий этап.

## Открытые решения

| Решение | Что даёт | Ограничения и решение для MVP |
|---|---|---|

| [ts-fsrs](https://github.com/open-spaced-repetition/ts-fsrs) | Планирование повторений карточек; MIT | Рекомендуется как готовая библиотека. Нужно реализовать интерфейс и хранение состояния; выбранную версию проверить при сборке. |
| [Anki](https://github.com/ankitects/anki) | Готовое приложение карточек с повторением, текстом и аудио | Быстрый самостоятельный вариант на компьютере; не основа простого сайта на GitHub Pages. Лицензии компонентов следует сверить перед заимствованием. Возможен последующий экспорт наших карточек. |
| [LibreLingo](https://github.com/LibreLingo/LibreLingo) | Готовая языковая платформа, Svelte, курсы в YAML; AGPL-3.0 | [Документация](https://github.com/kantord/LibreLingo/tree/main/docs/courses) отмечает недостаток возможностей обучения новому алфавиту. Готовый курс русского для испаноговорящих в просмотренных источниках не подтверждён. Потребует адаптации. |
| [H5P](https://h5p.org/licensing) | Интерактивные задания и презентации | Удобно для редактора уроков, но стандартные интеграции требуют CMS/сервера. Лицензии смешанные: многие компоненты MIT, PHP-библиотека GPL. Для первого статического сайта избыточно. |
| [OpenLingo](https://github.com/pretzelai/openlingo) | AI-тьютор, карточки, русский, TTS/STT; MIT | Требует PostgreSQL, авторизации и внешних сервисов AI/аудио. Перспективен позже; не соответствует простому локальному старту без API-ключей. |

Исследование основано на найденных официальных страницах и репозиториях, а не на установке и испытании каждой платформы. Бесплатный доступ к материалу не равен разрешению копировать его. Лицензии учебных материалов проверяются отдельно от кода. Первые уроки предлагается написать самостоятельно и проверить у носителя русского и испанского.

## Варианты

1. **Рекомендуемый:** небольшой статический сайт, reveal.js + ts-fsrs. Собственный понятный интерфейс, запуск локально и на GitHub Pages, без платных API. Нужна разработка оболочки и уроков.
2. **Самый быстрый готовый инструмент:** Anki с собственной русско-испанской колодой. Хорош для проверки учебного материала, но уроки-слайды и персональный интерфейс потребуют отдельного решения.
3. **Адаптация платформы:** LibreLingo или H5P. Больше готовых учебных механизмов, больше работы с инфраструктурой и адаптацией.

## Предлагаемое устройство MVP

- Статический веб-сайт на TypeScript и Vite; сборка с локальными зависимостями, без загрузки библиотек с CDN при каждом занятии.
- Главная страница на испанском, список тем и кнопка продолжения.
- Шесть вводных тем: знакомство с буквами, приветствия, представление себя, семья, числа 1–10, любимые вещи.
- Каждая тема: 4–6 коротких слайдов, 6–8 карточек, несколько упражнений выбора и ввода. Первые слова выбираются так, чтобы не требовать знания всего алфавита.
- Подсказки по чтению на испанском, ударения, постепенное уменьшение транслитерации. Транслитерация — приблизительная опора, а не точная передача произношения.
- Карточки повторения через ts-fsrs с понятными оценками на испанском. Состояние каждой карточки хранится отдельно.
- Прогресс в localStorage, экспорт и импорт JSON с проверкой формата. Очистка данных браузера без резервной копии удалит прогресс; автоматической синхронизации устройств в MVP нет.
- Курс хранится отдельно от интерфейса в структурированных файлах. Можно менять уроки через GitHub.
- Адаптация к телефону, крупные кнопки, клавиатурная навигация, спокойная обратная связь без наказаний за ошибки.
- Приёмка: запуск по README, прохождение урока, сохранение после перезагрузки, корректные сроки повторения, экспорт/импорт, работа на мобильной ширине и отсутствие ошибок консоли.

## Голосовой этап

[SpeechSynthesis.getVoices](https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesis/getVoices) позволяет озвучить текст доступными голосами устройства. Наличие русского голоса и качество проверяются на конкретном устройстве. Браузерная озвучка не обеспечивает экспорт голосового сообщения в аудиофайл.

[Web Speech API](https://developer.mozilla.org/en-US/docs/Web/API/Web_Speech_API/Using_the_Web_Speech_API) поддерживает диктовку, но по умолчанию распознавание может передавать аудио внешнему сервису. Локальное распознавание требует совместимого браузера и языкового пакета; поддержку русского нельзя предполагать заранее. Распознавание текста само по себе не оценивает произношение.

Для воспроизводимых аудиосообщений можно заранее создать и сохранить аудиофайлы уроков. Для динамической генерации аудио и локальной диктовки потребуется отдельный локальный сервис; кандидаты Whisper/Piper нуждаются в дополнительной проверке актуальных репозиториев, лицензий голосовых моделей и требований к компьютеру. GitHub Pages такой сервер не запускает.

## Размещение

Код, уроки и документация — GitHub. Секреты, личный прогресс и записи голоса — вне репозитория. GitHub Pages может разместить статическую сборку, если нужен доступ Мии из Коста-Рики. Хранение исходников на GitHub само по себе не создаёт работающий сайт.

Текущая /workspace — рабочая среда ассистента, не компьютер пользователя. Для размещения на компьютере пользователя нужен перенос проекта и запуск по инструкции. Имя/владелец GitHub-репозитория и ОС пользователя пока неизвестны; публикация не выполнялась.
