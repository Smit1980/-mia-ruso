# Публикация мобильных уроков

Готовая версия: docs/index.html и docs/assets. Шесть уроков с полным содержанием: [lessons.md](lessons.md).

Проверено 5 октября 2026 года в GitHub Actions: обычная сборка, тесты API, приватная переписка в двух браузерных сессиях, статическая сборка, шесть уроков, слайды, ввод кириллицы, упражнения, сохранение прогресса, карточки FSRS и отсутствие горизонтального переполнения на ширинах 320, 375, 390, 768 и 1366 px. Отчёт: [pages-verification.json](pages-verification.json). Проверка живого сайта пока не проводилась.

Автоматическое включение Pages отклонено GitHub: 403 Resource not accessible by integration. Для публикации владелец репозитория должен открыть https://github.com/Smit1980/-mia-ruso/settings/pages и выбрать Source: Deploy from a branch; Branch: main; Folder: /docs; затем Save.

Ожидаемый адрес: https://smit1980.github.io/-mia-ruso/ . Его доступность нельзя считать подтверждённой до включения Pages и завершения публикации.

В учебной версии можно учиться без сервера. Отправка сообщений и закрытый вход доступны только в полной серверной версии.
