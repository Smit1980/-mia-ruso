# Проверка MVP

Проверено в рабочей среде: Node.js 24.19.0, Chromium через Playwright.

- `npm run build`: проверка типов TypeScript и production-сборка Vite проходят.
- `npm test`: интеграционная проверка API проходит. Проверяет закрытый доступ, роли, валидацию, Origin, идемпотентную отправку, ответы, отзыв приглашения, выход и повторное открытие SQLite.
- `node tests/browser.mjs`: вход по ссылке, смена слайда, прохождение упражнения с экранной клавиатурой, прогресс после перезагрузки, карточка FSRS, переписка в двух независимых контекстах, безопасное отображение HTML как текста, черновик при сбое сети, экспорт/импорт и отказ повреждённому импорту проходят.
- Мобильная ширина 390 px: горизонтального переполнения нет. Скриншоты в `docs/screenshots/`.
- `npm audit --omit=dev`: у установленных production-зависимостей известных уязвимостей не обнаружено на момент проверки.

Тесты используют временную базу и вымышленные сообщения. Реальные приглашения в исходники не входят. Проверка на реальном телефоне Мии, production HTTPS и сетевое соединение Коста-Рика—Россия пока не выполнялись. Docker-конфигурация подготовлена, но контейнер не запускался.

GitHub: репозиторий https://github.com/Smit1980/-mia-ruso доступен на запись через ChatGPT Codex Connector после установки приложения в аккаунте Smit1980. Перед загрузкой повторно прошли сборка, API-тест и полный браузерный сценарий. Реальная база, приглашения, сессии и личный прогресс в исходники не входят. Репозиторий публичный.
