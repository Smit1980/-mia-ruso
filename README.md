# 🌱 Hola, ruso — русский для Мии

Первый MVP для испаноговорящей ученицы: шесть уроков русского, слайды, 40 карточек с интервальным повторением, упражнения и закрытая Доска для переписки с семьёй.

## Локальный запуск (Windows / macOS / Linux)

Установите **Node.js 24 LTS**. Скачайте проект или клонируйте репозиторий:

```sh
git clone https://github.com/Smit1980/-mia-ruso.git
cd ./-mia-ruso
```
 В терминале в папке проекта:

```sh
npm ci
npm run build
npm start
```

Откройте второй терминал в этой же папке и создайте приглашения:

```sh
npm run invite -- mia
npm run invite -- family
```

Откройте первую выданную ссылку в обычном браузере, вторую — в другом браузере или отдельном приватном окне. Ссылка автоматически создаёт сессию на 30 дней, затем адрес очищается от ключа. Почта и пароль не нужны. Повторный выпуск ссылки для роли отзывает предыдущую ссылку и её сессии.

```sh
npm run invite -- mia --revoke
```

Входы принадлежат Мии и родственнику. Доска доступна только им, но **любой владелец персональной ссылки получает соответствующий доступ**. Не размещайте ссылки в GitHub и не отправляйте их в публичные чаты.

## Разработка

В двух терминалах: `npm run server` и `npm run dev`. Для dev используйте `APP_ORIGIN=http://localhost:5173` при запуске сервера и создании приглашений, затем открывайте ссылку через порт 5173. На Windows PowerShell: `$env:APP_ORIGIN="http://localhost:5173"`; на macOS/Linux: `APP_ORIGIN=http://localhost:5173 npm run server`.

## Что есть

- Испанский интерфейс и русские слова с ударениями и приблизительными подсказками чтения.
- Слайды reveal.js, явные кнопки навигации, упражнения выбора и ввода с экранной русской клавиатурой.
- Карточки ts-fsrs: «ещё раз», «вспомнила», «легко»; очередная сессия до 10 карточек.
- Прогресс этого браузера, экспорт/импорт JSON. На другом устройстве нужно импортировать копию; автоматической синхронизации прогресса нет.
- Темы и ответы на Доске, дата и автор, обновление каждые 15 секунд. Доска пока на испанском; писать можно на любом языке. Согласно текущему запросу переход переписки — с испанского на английский.
- Сообщения общие, хранятся в SQLite. Нет публичной регистрации, email, рекламы и аналитики.

## GitHub и доступ между странами

Целевой репозиторий для загрузки исходников: [Smit1980/-mia-ruso](https://github.com/Smit1980/-mia-ruso).

`data/`, приглашения и локальный прогресс не включаются в исходники. **GitHub Pages не запускает сервер Доски**. Для Мии в Коста-Рике и семьи в России разместите полный проект на Node.js-хостинге/VPS с постоянным диском, HTTPS и Node.js 24. Один экземпляр backend обслуживает базу; не используйте эфемерный диск или несколько независимых экземпляров.

Production-переменные:

```text
NODE_ENV=production
APP_ORIGIN=https://your-domain.example
PORT=3000
DB_PATH=/persistent/mia/mia.sqlite
```

После `npm ci && npm run build` запустите `npm start`. HTTPS обеспечивает reverse proxy или платформа. `APP_ORIGIN` должен точно совпадать с адресом сайта (без конечного `/`). С этими же `DB_PATH` и `APP_ORIGIN` создайте приглашения на сервере. В production cookie защищены Secure; через обычный HTTP вход работать не будет. Не проксируйте с записью `/join/…` в access-логи: этот URL содержит ключ приглашения. Приложение само ключи не логирует.

Контейнер: `docker build -t mia-ruso .`, затем запускайте с постоянным volume `/app/data` и указанными выше production-переменными за HTTPS-прокси. Административная команда внутри контейнера: `docker exec CONTAINER node server/invite.mjs mia`.

## Резервные копии

Самый простой способ: остановите сервер, скопируйте всю папку `data/` в закрытое место и снова запустите сервер. Для восстановления остановите сервер и верните сохранённую папку. SQLite использует WAL: **не копируйте только основной файл базы при работающем сервере**. Копия содержит сообщения и данные доступа; не публикуйте её в GitHub. Прогресс уроков экспортируется отдельно через «Mi progreso».

## Проверка

```sh
npm test
npm run build
```

Тест API проверяет обе роли, ответы, валидацию, повторы запросов, защиту по Origin, отзыв доступа и сохранность базы. Браузерная проверка: `npx playwright install chromium`, затем `node tests/browser.mjs` (создаёт временную базу и завершает сервер). На Linux могут понадобиться системные библиотеки Chromium.

## Структура

`src/course.ts` — контент; `src/progress.ts` — повторение и прогресс; `src/main.ts` — учебный интерфейс; `src/board.ts` — Доска; `server/` — API, доступ и SQLite. Исследование в `docs/research.md`, проект MVP в `docs/design.md`.
